# HabitFlow — Трекер привычек, планировщик задач и статистика продуктивности (MVP)

**HabitFlow** — минималистичное веб-приложение для студентов, начинающих специалистов и всех, кто хочет объединить ежедневные привычки и задачи с дедлайнами на одном спокойном экране без перегруженных комбайнов вроде Notion.

---

## ✨ Основные возможности MVP

1. **Главная панель «Фокус на сегодня»:**
   - Сводка дня: прогресс привычек, лучшая активная серия, задачи на фокусе и общий индекс продуктивности (`0–100`).
   - Быстрый чек-лист привычек на сегодня и список сегодняшних / просроченных задач.
2. **Трекер привычек и подсчёт серий (Streaks):**
   - Создание, редактирование и удаление привычек (с выбором иконки, HEX-цвета и недельной цели).
   - Честный расчёт текущей непрерывной серии (`current_streak`) и рекорда (`best_streak`).
   - Защита на уровне БД (`UniqueConstraint`) от дублирования отметок одной привычки за одну дату.
3. **Календарь привычек за месяц:**
   - Тепловая карта (heatmap) месяца с процентом выполнения за каждый день.
   - Поденная матрица всех привычек с возможностью отметить или снять выполнение за любой прошедший день месяца.
4. **Планировщик задач:**
   - Задачи с дедлайнами (`due_date`), приоритетами (`low`, `medium`, `high`), статусами (`todo`, `in_progress`, `done`) и категориями.
   - Автоматическая подсветка просроченных задач и фильтрация по статусу и приоритету.
5. **Статистика за неделю (7 дней) и месяц (30 дней):**
   - Процент выполнения привычек, количество закрытых задач (включая высокий приоритет), график динамики по дням и рейтинг серий.
6. **Проверка спроса на монетизацию (HabitFlow Pro Fake Door):**
   - Встроенное модальное окно раннего доступа к тарифу **HabitFlow Pro** с сохранением контактов и самой желанной фичи в таблицу `pro_waitlist`.

## 🛠 Технологический стек

- **Backend:** Python 3.9+, FastAPI, Uvicorn, Pydantic v2 (`pydantic-settings`).
- **Database:** SQLite, SQLAlchemy 2.0 ORM (`PRAGMA foreign_keys=ON`, каскадное удаление, ограничения уникальности).
- **Frontend:** HTML5 (Jinja2), адаптивный современный CSS3 (Flexbox / CSS Grid), модульный Vanilla JavaScript (`fetch` API).
- **Тестирование:** `pytest`, `httpx` (`TestClient` с изолированной in-memory SQLite БД).

## 🚀 Быстрый запуск локально

### 1. Перейдите в папку проекта
```bash
cd /Users/5ayan52/habitflow
```

### 2. Создайте и активируйте виртуальное окружение (если ещё не создано)
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. (Опционально) Создайте файл настроек `.env`
```bash
cp .env.example .env
```

### 5. Запустите сервер разработки
```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

После запуска откройте в браузере:
- **Веб-приложение:** [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **Swagger UI (интерактивная документация API):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

> 💡 **Совет для быстрого знакомства:** Нажмите кнопку **«⚡ Демо-данные»** в правом верхнем углу интерфейса — приложение автоматически создаст примеры привычек, историю серий за 12 дней и задачи с дедлайнами.

## 🔌 Основные эндпоинты REST API

- `GET /api/habits` — список привычек с сериями (`current_streak`, `best_streak`).
- `POST /api/habits` — создать привычку.
- `PUT /api/habits/{id}` — обновить привычку.
- `DELETE /api/habits/{id}` — удалить привычку.
- `POST /api/habits/{id}/checkins` — строгая запись выполнения за дату (`409 Conflict` при дубле).
- `POST /api/habits/{id}/toggle` — переключить отметку за дату и пересчитать серию.
- `GET /api/tasks` — список задач (поддерживает фильтры `?status=...&priority=...&due_date=...`).
- `POST /api/tasks` — создать задачу.
- `PUT /api/tasks/{id}` / `PATCH /api/tasks/{id}` — обновить задачу или сменить статус.
- `DELETE /api/tasks/{id}` — удалить задачу.
- `GET /api/stats/dashboard` — сводка для главного экрана «Сегодня».
- `GET /api/stats/calendar?year=YYYY&month=MM` — календарь привычек за месяц.
- `GET /api/stats/summary` — статистика продуктивности за 7 и 30 дней.
- `POST /api/stats/seed` — заполнить пустую базу демо-данными.
- `POST /api/stats/waitlist` — оставить заявку на ранний доступ к тарифу **HabitFlow Pro**.
